SAT Reading & Writing — Hard Questions

This is a static website containing 610 SAT Reading & Writing questions.

To run locally:
1. Open PowerShell in this folder.
2. Run: python -m http.server 8000
3. Open http://localhost:8000

To publish with GitHub Pages:
1. Upload the contents of this folder to the root of your public GitHub repository.
2. In Settings > Pages, choose Deploy from a branch, branch main, folder /(root).

Visual questions now include cropped original graph/table images from the source PDF.
The original PDF is intentionally not included in this package.
